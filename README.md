# SwiftBoard

SwiftBoard is a drag-and-drop task board inspired by Trello.

## Features

- Create tasks
- Move tasks between columns
- Delete tasks by dragging them to the trash zone
- Day Overview with daily statistics
- Progress indicators
- LocalStorage data saving
- Archive and history sections

## Technologies

- JavaScript
- HTML
- CSS
- Webpack
- Drag and Drop API
- LocalStorage
